# Al-Mustapha Umar | SEO Content Writer Portfolio

A lightweight responsive portfolio built with HTML, CSS and vanilla JavaScript for GitHub Pages.

## Site structure
- `index.html` - homepage with profile, services, experience and three featured writing samples
- `about.html` - profile, skills, education and SEO/content experience
- `contact.html` - email and LinkedIn contact page
- `articles/finance/personal-budget.html` - Personal Finance writing sample
- `articles/technology-ai/ai-future-of-work.html` - Technology and AI writing sample
- `articles/seo/what-is-seo.html` - SEO writing sample
- `css/style.css` - site styling
- `js/script.js` - mobile navigation and shared behavior
- `assets/images/` - local images and article artwork
- `assets/favicon.svg` - favicon
- `robots.txt` and `sitemap.xml` - search engine files

## Navigation
The main site navigation contains only Home, About and Contact. There is no separate My Work page or Articles listing page. The homepage displays the three selected writing samples, and each sample opens its own article page.

## Profile photo
Add the professional photo to `assets/images/` and update the profile image `src` in `index.html` if you have not already done so.

## Article images
The three featured article images are displayed on the homepage and on their respective article pages. Keep image filenames descriptive and use descriptive alt text.

## GitHub username
Replace `YOUR-GITHUB-USERNAME` in canonical URLs, Open Graph URLs, `robots.txt`, and `sitemap.xml` with the actual GitHub username when the final Pages URL is known.

## Local testing
Open `index.html` in a browser or use a simple local static server. Test the Home, About, Contact and three article links, including the mobile menu.

## GitHub Pages
Upload the project contents to the repository named `SEO-Portfolio`, keeping `index.html` at the repository root. In Repository Settings > Pages, use Deploy from a branch, select `main`, and select the root folder.

## Truthfulness
The site contains no invented clients, employers, rankings, traffic statistics, testimonials, awards or publications. The three articles are portfolio writing samples.
